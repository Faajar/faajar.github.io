Konten Managemen

Kebijakan Privasi

Berlaku sejak 11 November 2026.

Tentang aplikasi ini

Konten Managemen adalah aplikasi pribadi yang berjalan di laptop pemiliknya. Aplikasi ini menjadwalkan dan mengunggah video ke channel YouTube milik pemilik itu sendiri, lalu membaca statistik video tersebut. Aplikasi ini bukan layanan publik: tidak ada pendaftaran, tidak ada pengguna lain, dan tidak ada server di internet selain layanan Google.

Data Google yang diakses

Aplikasi ini memakai YouTube API Services dan hanya meminta dua izin:

  • Mengunggah video (youtube.upload): mengirim video yang dipilih pemilik ke channel-nya, beserta judul, deskripsi, kategori, dan jadwal tayang.
  • Melihat akun YouTube (youtube.readonly): membaca nama dan ID channel, serta jumlah views, likes, dan komentar video yang diunggah atau dicatat di aplikasi.

Aplikasi ini tidak membaca email, kontak, file Drive, atau data Google lainnya.

Cara data dipakai

Data di atas hanya dipakai untuk menjalankan fungsi tersebut: mengunggah video pada jadwalnya dan menampilkan statistiknya kepada pemilik. Data tidak dijual, tidak dibagikan kepada pihak lain, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI.

Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Penyimpanan

Token akses Google, nama dan ID channel, serta angka statistik disimpan di satu file database di laptop pemilik. File itu tidak diunggah ke mana pun. Aplikasi berkomunikasi langsung dengan server Google, tanpa perantara.

Mencabut akses dan menghapus data

  • Tombol Putuskan di halaman Pengaturan aplikasi mencabut izin di Google dan menghapus token dari laptop.
  • Izin juga bisa dicabut kapan saja di halaman izin akun Google.
  • Seluruh data aplikasi terhapus bila file database aplikasi dihapus dari laptop.

YouTube dan Google

Dengan memakai aplikasi ini, pemilik terikat pada Persyaratan Layanan YouTube. Data yang diproses Google mengikuti Kebijakan Privasi Google.

Cookie

Aplikasi dan halaman ini tidak memakai cookie pelacak atau layanan analitik.

Kontak

Pertanyaan tentang kebijakan ini bisa diajukan lewat halaman Issues repository situs ini.

In English

Konten Managemen is a personal app that runs on its owner's laptop. It uses YouTube API Services to upload the owner's own videos to the owner's own channel (scope youtube.upload) and to read that channel's name, ID and video statistics (scope youtube.readonly). This data is used only for those features, is stored only in a local database file on the owner's laptop, and is never sold, shared, used for advertising or used to train AI models.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked with the app's Putuskan button or at Google account permissions; deleting the local database file removes all app data. Use of the app is subject to the YouTube Terms of Service and the Google Privacy Policy. Contact: the Issues page of this site's repository.
